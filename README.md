# Sistema de Consola con Menú - Proyecto Grupal (Evaluación 06)

## Descripción del Sistema
Este sistema de consola en C# simula un punto de venta y gestión para una tienda tecnológica. Permite calcular subtotales, aplicar ITBIS, consultar un catálogo de ofertas mediante ciclos y registrar ventas rápidas validando entradas de usuario.

## Requisitos Técnicos Implementados
- **Menú Interactivo:** Estructura con `do-while` y `switch` (4 opciones principales + salida).
- **Métodos Modulares:** Se implementaron más de 4 métodos personalizados (con y sin parámetros, con y sin retorno).
- **Validación de Datos:** Uso estricto de `int.TryParse` y `double.TryParse` para evitar excepciones por errores de usuario.
- **Estructuras de Control:** Uso de `if`, `switch` y bucles `for`.
